# Welcome to Sholatro!

an 100% btd6 related mod with an intention of being extremely unbalanced (still more balanced than average nk updates)

requires [Steamodded](https://github.com/Steamodded/smods/releases/latest), consider downloading [Talisman](https://github.com/SpectralPack/Talisman/releases/latest)/[Cryptlib](https://github.com/SpectralPack/Cryptlib/releases/latest) or perhaps even [Cryptid](https://github.com/SpectralPack/Cryptid/releases/latest) for a more bizarre experience

# What is this mod about?
this is a mod about everything I found funny/interesting and decided to add into the game, which includes:
- unbalanced ideas
- inside jokes that are not really funny
- towers in btd6 old versions that absolutely peaked/sucked during the period

# I prefer vanilla balance but i still want to see bloons content...
